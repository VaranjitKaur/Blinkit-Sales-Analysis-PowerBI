# 🚀 Blinkit Sales Analysis Dashboard | Power BI

## 📊 Project Overview

This is my first Power BI dashboard project, focused on analyzing Blinkit's sales performance, customer preferences, and outlet characteristics.

The goal of this project is to transform raw sales data into meaningful business insights through interactive visualizations and an easy-to-use dashboard.

## 🎯 Project Objectives

- Analyze overall sales performance and key performance indicators (KPIs).
- Track average sales, average ratings, and item-level performance.
- Evaluate outlet performance across different locations and sizes.
- Explore sales distribution by item type and fat content.
- Identify trends and patterns to support data-driven decision-making.

## 📈 Dashboard Features

- **Total Sales Analysis:** Overview of overall sales performance.
- **Average Sales & Ratings:** Track average sales and customer ratings.
- **Outlet Performance:** Compare sales across different outlet types.
- **Item Type Analysis:** Understand sales distribution across product categories.
- **Fat Content Analysis:** Compare sales by fat content.
- **Outlet Size & Location:** Analyze performance by outlet size and location tier.
- **Interactive Filters:** Use slicers to explore specific segments of the data.
- **Reset Functionality:** Return the dashboard to its default view.
- **Dynamic Visualizations:** Interactive charts and KPI cards for better analysis.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **DAX** – Measures and KPI calculations
- **Power Query** – Data cleaning and transformation
- **Data Modeling** – Organizing data for analysis
- **Data Visualization** – Presenting insights through interactive charts
